Phase 1（第 1-2 月）：地基与稳健收益

🟦 目标：$200-500 起步，学会选市场、执行交易、记录复盘，月回报 3-8%

策略 A：临期确定性理财

低风险 Sharpe 1.9 年化 30-50% 临期 NO 吃利息

核心逻辑：在即将到期的市场中，如果某事件几乎不可能发生（NO 概率 > 95%），买入 NO 份额。到期后 NO 结算为 $1.00，你赚取买入价与 $1.00 之间的差价。

举例：LeBron James 退役市场，NO 报价 $0.99，10 月 20 日到期。你花 $99 买 100 股 NO。到期 LeBron 没退役 → NO 结算 $1.00 → 你拿回 $100，赚 $1。看起来少，但如果 7 天到期的市场，年化 = (1/99) × (365/7) ≈ 52.6%。

选市标准（必须全部满足）

条件 标准 原因
NO 概率 ≥ 95%（即 NO 价格 ≤ $0.05） 足够高的确定性
到期时间 1-30 天 资本效率：越快到期年化越高
市场交易量 > $10,000 确保流动性，能买入和退出
价差（Spread） ≤ 3 cents 买入卖出价差小，不吃亏
结算规则 清晰无歧义 避免灰色地带导致争议
黑天鹅风险 低（非政治/地缘类优先） 避免突发新闻翻转

入场操作流程

1
筛选市场 打开 polymarket.com → 按 "Ending Soon" 排序 → 逐一检查 NO 概率 > 95% 的市场
辅助工具：predscope.com/stats 查看 90-100% 概率区间的市场（当前有 356 个）
2
验证确定性 读结算规则 → 确认结算数据源 → 评估黑天鹅概率
问自己：未来 N 天内，有什么事件能让 YES 变成现实？如果没有，入场。
3
计算年化收益
年化收益 = (1 - NO价格) / NO价格 × (365 / 到期天数) 示例：NO价格 $0.97，3天到期 年化 = (0.03 / 0.97) × (365 / 3) = 0.0309 × 121.7 = 376% 示例：NO价格 $0.99，30天到期 年化 = (0.01 / 0.99) × (365 / 30) = 0.0101 × 12.17 = 12.3%
目标：年化 > 30% 的才值得做。3-7 天到期的性价比最高。
4
下单（限价单！） 始终用限价单（Limit Order），0% 手续费
在当前 NO Ask 价基础上压低 0.5-1 cent 挂单
如果 30 分钟未成交，调整到 Ask 价或取消
5
记录日志 立即在交易日志中记录：市场名、方向(NO)、买入价、数量、金额、到期日、年化、确定性理由

出场规则

  • 正常持有到期：这是主要方式。NO 结算 $1.00，自动到账。
  • 提前退出：如果出现可能改变结果的消息（哪怕概率很小），立即以当前价卖出。不要赌。
  • 止盈：如果 NO 价格从 $0.95 涨到 $0.98+，可以卖出锁定利润，释放资金做下一个。

策略 B：马斯克推文预测（学习模式）

中风险 7天周期 新手推荐 推文区间桶交易

核心逻辑：Polymarket 每周发布"马斯克下周发多少条推文"的预测市场，按数量分成多个区间桶（如 200-219、220-239、240-259），只有最终落在哪个桶，YES 结算 $1.00。

为什么适合新手：数据完全公开透明（xtracker.polymarket.com 实时追踪），7 天结算周期快，流动性高（$528K/24h），规律性强（日均 20-40 条）。

推文预测方法论

步骤 操作 工具
1. 查看当前进度 访问 xtracker.polymarket.com，看本周已发推文数和日均速率 xtracker.polymarket.com
2. 计算 projected 总数 当前数 / 已过天数 × 7 = 预测总数 手算/表格
3. 对比历史模式 参考过去 4-8 周的发帖规律：工作日 vs 周末、有无重大事件 xtracker 历史数据
4. 评估催化因素 Tesla 财报/SpaceX 发射/xAI 发布/政治事件 → 推文量飙升 新闻监控
5. 定位目标桶 找到 projected 总数最可能落入的 1-2 个桶 —
6. 检查桶价格 如果目标桶 YES 价格 < 你估算的概率，买入 Polymarket 市场页
桶交易进阶技巧：买入相邻 2-3 个桶（如 220-239 + 240-259），如果多个桶 YES 价格之和 < $0.90，相当于用 $0.90 买了一个 90%+ 概率的事件，存在正期望值（+EV）。这是 @noovd 风格的经典策略。

入场时机

  • 最佳入场：周一或周二初，此时数据少、价格波动大、定价偏差多
  • 次佳入场：周三-周四，已有 3-4 天数据，projected 更准确，但价格也更有效
  • 避免入场：周五-周六，价格已充分定价，剩余空间小
  • 关键操作：每天检查 xtracker 1-2 次，如果实际推文速率大幅偏离预期，及时调整

策略 D：专业领域方向性交易

高风险 高回报 需专业知识 利用你的信息优势

核心逻辑：在你最懂的领域（电竞、NBA、加密、AI 行业、地缘政治），找到市场定价偏差，下注你认为正确的方向。这是赚大钱的核心策略——顶级交易者 "Swisstony" 以此在体育市场赚了 $370 万。

方向性交易操作框架

1
写下你的概率估算（在看价格之前） 基于你的专业知识，先独立估算事件发生的概率。这避免锚定效应。
2
对比市场价格 如果你的估算与市场价格的差距 > 10%，可能存在 edge。
Edge = 你的估算概率 - 市场隐含概率 示例：你估算某队赢球概率 70%，市场 YES 价格 $0.55（55%） Edge = 70% - 55% = 15% → 有明显 edge，可入场
3
用 Kelly 公式计算仓位
Kelly 公式：f* = (b × p - q) / b b = 净赔率 = (1 / 市场价格) - 1 p = 你的估算概率 q = 1 - p 实际使用 Half Kelly（除以 2） 示例：市场价 $0.55，你估算 p = 70% b = (1/0.55) - 1 = 0.818 f* = (0.818 × 0.70 - 0.30) / 0.818 = (0.573 - 0.30) / 0.818 = 0.334 Half Kelly = 0.334 / 2 = 16.7% → 但受 5% 仓位上限约束，实际下 5%
4
设限价单入场 在当前价格基础上压低 1-2 cent 挂限价单。0% 手续费。
5
持续跟踪 每天检查相关信息流。如果新信息改变了你的概率估算，重新评估是否持有。

Phase 3（第 5-6 月+）：进阶与半自动化

🟪 目标：$5K-10K+，半自动化运营，月回报 10-20%

策略 E：信息套利

中高风险 时间敏感 小资金友好 新闻事件后的价格滞后

核心逻辑：Polymarket 的参与者以散户为主，价格调整速度比传统金融市场慢 5 分钟到 2 小时。当重大新闻发生时，如果你能在市场反应前入场，就能获得巨大 edge。

信息套利操作要点

  • 监控关键信息源：Twitter/X（设置关键人物通知）、Bloomberg、ESPN、官方公告页
  • 关联市场地图：提前列出"如果 X 发生，哪些市场会受影响"的映射表
  • 执行速度：从看到新闻到下单 < 3 分钟。提前在 Polymarket 上看好相关市场页面的 URL
  • 典型场景：
    • NBA 球员伤病报告发布 → 赛事胜负市场调整滞后
    • 美联储利率决议 → 加密涨跌市场反应延迟
    • AI 公司突然发布新模型 → "某模型何时发布"市场立即结算
    • 政治人物突然宣布退选/参选 → 相关选举市场剧烈波动

策略 F：半自动化推文交易

低风险 自动化 需技术配置 XTracker + 自动下单

核心逻辑：利用开源工具（如 polymarket-elon-tweets SDK），自动监控 XTracker 的推文计数和市场价格，当相邻桶的总价 < $1 时自动买入，锁定统计套利。

自动化搭建步骤

  1. 安装 Simmer SDK：pip install simmer-sdk
  2. 获取 Simmer API Key（simmer.markets/dashboard）
  3. 配置钱包私钥（环境变量 WALLET_PRIVATE_KEY）
  4. 设置参数：最大仓位 $10/桶、买入相邻 1 个桶、退出阈值 $0.95
  5. 先 dry run（python elon_tweets.py），观察 1-2 周
  6. 确认策略有效后开启 live 模式（--live --smart-sizing）
  7. 设置 cron 每小时运行一次（--quiet 模式）
⚠️ 自动化风险提示：自动交易会放大错误。务必先用 dry run 模式运行至少 2 周，确认逻辑正确后再开 live。设置每日最大亏损限制，超过后自动停止。

风控体系（全阶段通用）

仓位管理

规则 标准 说明
单笔仓位上限 ≤ 5% 总资金 $500 资金 → 单笔 ≤ $25；$5,000 → ≤ $250
单类别仓位上限 ≤ 30% 政治类、体育类、加密类等每个类别最多 30%
同时持仓数 6-25 个（随阶段递增） 分散到不同不相关的市场
现金储备 ≥ 30% 随时保持弹药，等待新机会
新手保护期 前 100 笔交易 ≤ 2% 未验证 edge 前极度保守

回撤应对计划

回撤幅度 应对措施 状态
回撤 10% 正常波动。继续交易，检查近期交易是否有流程错误 🟢 正常
回撤 20% 仓位减半。审查概率估算是否有校准问题 🟡 警戒
回撤 30% 停止交易一周。全面复盘所有交易。仅在找到可纠正错误后才恢复 🔴 危险
回撤 40%+ 考虑退出。重新评估是否适合预测市场交易 ⛔ 紧急

绝对禁止事项

  • 不用借来的钱交易
  • 不用生活必需资金交易
  • 不在亏损后加仓"回本"（Tilt 交易）
  • 不在不理解的结算规则的市场交易
  • 不在流动性 < $10K 的市场交易
  • 不把超过 30% 资金投入单一事件
  • 不在情绪激动时下单（赢了大涨后、亏了之后）
  • 不忽略手续费（虽然限价单 0%，但市价单有 0.5-2%）
  • 不做"无聊交易"——没机会就不交易，空仓也是一种策略
  • 不忘记记录每一笔交易

20 条铁律

  1. 只用限价单，0% 手续费。市价单是给急的人准备的，急的人亏钱。
  2. 单笔 ≤ 5% 仓位，新手期 ≤ 2%。这条规则救过无数人的账户。
  3. 保持 30% 现金。没有现金就抓不到新机会，机会永远在你不准备的时候来。
  4. 同时持 6-10+ 个不相关仓位。相关性是隐形杀手——同类的市场一起涨一起跌。
  5. 只交易量 > $10K 的市场。低流动性市场进得去出不来。
  6. 在看价格前写下你的概率估算。避免锚定效应。
  7. 读完整结算规则再下单。不理解的结算规则 = 赌博。
  8. 记录每一笔交易。不记录的交易等于白做，因为你无法从中学到东西。
  9. 亏损后停止 1 小时再交易。Tilt 交易是账户的头号杀手。
  10. 每周复盘。胜率、收益、错误、调整。进步来自复盘，不来自交易。
  11. 不用借来的钱，不用生活必需的钱。只用你能完全承受亏损的资金。
  12. 不加仓亏损仓位，除非有新的信息增强了你的论点。
  13. 设回撤停止线：-20% 减半仓位，-30% 停止一周。
  14. 资金翻倍后提取本金。之后你就是在用利润玩，心理压力大幅降低。
  15. 不追热点。FOMO 入场是亏钱的第二大原因（仅次于 Tilt）。
  16. 关注价差：如果买卖价差 > 4 cents，这不是一个好的入场市场。
  17. 提前退出比持有到期更安全，如果出现可能改变结果的消息。
  18. 聪明钱是确认信号，不是交易理由。先有自己的判断，再参考他们的。
  19. 地缘政治市场降低仓位。黑天鹅风险最高，一条新闻翻转一切。
  20. 无聊是好事。没有好机会就不交易。空仓也是一种策略。耐心等待 edge 出现。

最终忠告

预测市场的本质是概率游戏，不是赌博。长期盈利的人靠的不是运气，而是：

  • 信息优势——在你最懂的领域交易
  • 仓位纪律——永远不满仓，永远有现金
  • 持续复盘——从每笔交易中学习
  • 情绪控制——不追涨、不杀跌、不 Tilt

从 Phase 1 开始，用 $200-500 小资金练手。当你能连续 50 笔交易保持正 EV 时，再加大资金。慢慢来，比较快。
